  ---
  HIGH

  H1 — No API_TOKEN set in .env

  API_TOKEN= is empty. The require_api_access function in server/__init__.py:48-53 falls
  through to an IP check: only 127.0.0.1 / ::1 are allowed when no token is set. This means
  if Uvicorn is directly internet-reachable (no reverse proxy), every non-localhost request
  returns 403 — not great but better than open. However:

  - start_app.sh runs uvicorn ... --host 0.0.0.0 --port 8000
  - deploy/market-watch.service also binds --host 0.0.0.0 --port 8000

  If no nginx proxy sits in front, port 8000 is directly internet-exposed. The IP check
  would block unauthenticated access from the internet, but the require_api_access
  dependency is not applied to any router (zero results from grep). So the protection exists
   in code but is not wired to any actual routes. All routes are currently unauthenticated.

  H2 — /docs and /redoc endpoints exposed

  server/main.py:68-69 enables FastAPI's interactive docs at /docs and /redoc. These
  enumerate every API endpoint, their parameters, and allow calling them from the browser.
  No auth is on these routes.

  H3 — start_app.sh runs with --reload

  The startup script uses uvicorn ... --reload. This is a development flag that watches
  files for changes and hot-reloads. It should never run on a production VPS — it adds
  overhead and is not suitable for production use. The systemd service file correctly omits
  --reload, so this only matters if someone launches via start_app.sh on the VPS.
