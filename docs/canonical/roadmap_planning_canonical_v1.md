# Roadmap Planning Canonical v1

## Scope
Defines authoritative roadmap phase structure and execution-priority state.

## Invariants
- One canonical roadmap source controls phase status.
- Supporting strategy docs cannot silently override canonical phase states.

## Implementation Linkage
- NO (planning authority document)

## Test Linkage
- NO (planning authority document)

## Source Lineage
- Primary: `ROADMAP.md`
- Supporting: `STRATEGIC_ROADMAP_NEXT_PHASE.md`, `Roadmap Phase Snapshot.txt`, `SECTION 1 — Phase R2 Task Breakdown.txt`

## Conflict Notes
- Strategic roadmap and snapshot artifacts provide alternate phase framing and can drift from canonical roadmap status if unsynchronized.
